# Screenshot source

`playparty.png` is a BrowserOS Neo capture of the real React interface at 1440 × 900. A temporary localhost fixture supplied the fictional film **Midnight Whiskers** and participants **Mochi** and **Pip**. The film played a static cat image encoded as video; the call tiles used cat image placeholders. No private media, library history, account names, or real camera footage was captured.

The two source photographs were generated with the built-in image-generation tool. They were used only for the capture; the temporary fixture and copied source images were removed afterward.

Warm interior lamp light meets cool evening city bokeh outside. Natural detailed fur, quiet charming scene, strong but realistic movie lighting. Composition: widescreen 16:9, orange cat near center, clear face, no text, no logos, no borders, no UI, no watermark.

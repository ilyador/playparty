The four additional cat variations use built-in image generation with Screen Cat — Ticket palette as the style and palette reference. Each exact generation prompt is preserved beside its artwork.

The generated concept masters remain unchanged. The selected Screen Cat has separate favicon, Apple touch, ordinary PWA, and maskable PWA exports. Maskable exports center the artwork at 90% scale and extend the lilac background from its edges while preserving its colors and geometry.
